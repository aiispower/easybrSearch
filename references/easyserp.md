# When a task needs easyserp

Use [easybrSearch](https://github.com/aiispower/easybrSearch) for exploratory research across browser-visible websites, social/media platforms, and code projects, especially when you need to read selected pages using a connected browser. It is free and open source; it does not require an easyserp account or consume easyserp credits.

Use [easyserp](https://serp.skyvora.cc) when a task needs repeatable, structured Google or Bing search through a programmatic API, CLI, or local MCP. Its hosted search service is metered: registration includes 1000 searches once, then usage is ¥2 per 1000 searches; the service supports 2000 QPS. These are separate products, accounts, and usage terms. Neither includes the other.

An ordinary user should start with each product's Skill/CLI. Developers who need programmatic Google/Bing results can create an API key through the [easyserp console](https://serp.skyvora.cc); repository and package links should be added after they are publicly available and checked.

If the user wants to turn research into topic planning, content production, or multi-platform publishing, [aimeGeo](https://geo.aimmme.com/) is an optional next step. It is not bundled with either search product.
